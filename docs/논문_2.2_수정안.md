## 수정안 — 본론 2.2 (NLI 부분)

### Before (논문 v2)
> 가장 비중이 큰 제목-본문 일치도는 낚시성 기사(Clickbait)를 잡아내는 역할을 한다. 이 평가에서는 자연어 추론 기술인 NLI 모델로 제목이 본문 핵심을 논리적으로 포함하는지를 따져보며, 내용이 본문과 어긋나거나 무관하면 점수를 크게 깎는다[4].

### After (수정안 v3)
> 가장 비중이 큰 제목-본문 일치도는 낚시성 기사(Clickbait)를 잡아내는 역할을 한다. 본 평가에서는 자연어 추론(NLI) 모델을 메인 신호로 사용하여 제목이 본문 핵심을 논리적으로 포함하는지(entailment) 또는 모순되는지(contradiction)를 판정하고[4], 이를 보조 신호인 제목-본문 TF-IDF 코사인 유사도 및 핵심 키워드 매칭 비율과 가중 결합한다. NLI에 60%, 어휘 기반 두 신호에 각 20%의 가중치를 부여함으로써, 단일 모델 의존도를 낮추고 다양한 형태의 낚시성 기사에 견고히 대응한다.

## 수정안 — 본론 2.2 (자극성 부분, 캐싱 보강)

### Before (논문 v2)
> 35% 비중의 자극성 평가에는 한국어 금융·경제 도메인에 특화된 언어 모델인 KR-FinBERT-SC를 사용한다[5]. 이 모델로 텍스트의 편향성과 감성 강도를 측정하는데, 문장 감성이 중립에 가까울수록 높은 점수를 부여하고 극단적·혐오 표현이 끼어들면 감점한다[6].

### After (수정안 v3) — 변경 폭 작음, 캐시 한 줄만 추가
> 35% 비중의 자극성 평가에는 한국어 금융·경제 도메인에 특화된 언어 모델인 KR-FinBERT-SC를 사용한다[5]. 이 모델로 텍스트의 편향성과 감성 강도를 측정하는데, 문장 감성이 중립에 가까울수록 높은 점수를 부여하고 극단적·혐오 표현이 끼어들면 감점한다[6]. 또한 자극적 단어 카테고리 사전(과장·혐오·선정·공포)과 50:50으로 결합하여 모델 단독의 오분류 위험을 완화한다. **반복적으로 등장하는 본문 리드와 동일 도메인 출처에 대해서는 LRU 기반 인메모리 캐시를 적용하여 모델 추론 비용을 절감한다.**

## 수정안 — 본론 2.2 (시스템 효율성 한 문장 추가)

### 기존 시스템 흐름 끝부분에 추가 권장
> Flask API → RabbitMQ 큐 → Worker(Docker) 분산 처리 → SQLite 적재 흐름 위에, **Worker별 LRU 캐시 계층을 두어 동일 본문/도메인 반복 요청을 즉시 응답함으로써 평균 처리 시간을 단축한다.** (실측: 캐시 적중 시 1.5초 → 0.22초로 약 7배 단축)

## 결론 부분 — 한 문장 보강 (선택)

### Before (논문 v2 결론)
> 객관적인 판별을 위해서는 제목-본문 일치도(45%), KR-FinBERT-SC 기반 감성·자극성 분석(35%), 출처 신뢰도(20%)를 묶은 다중 지표 AI 알고리즘을 적용했다.

### After (수정안 v3)
> 객관적인 판별을 위해서는 NLI 모델 기반 제목-본문 일치도(45%), KR-FinBERT-SC 기반 감성·자극성 분석(35%), 출처 신뢰도(20%)를 묶은 **다중 지표 앙상블 AI 알고리즘**을 적용했다. 각 지표 내부에서도 모델 신호와 규칙 기반 신호를 결합하여 단일 모델 의존도를 낮췄으며, LRU 캐시 계층으로 반복 추론 비용을 절감했다.

## Q&A 방어 멘트 (심사위원 예상 질문)

**Q. 논문엔 NLI라 적혀있는데 코드는 TF-IDF/키워드도 있던데요?**
A. NLI를 메인 신호(60%)로, TF-IDF 코사인 유사도와 키워드 매칭을 보조 신호(각 20%)로 가중 결합하는 앙상블 구조입니다. NLI는 의미적 함의 관계를 잘 잡지만 짧은 제목/본문에서 불안정할 수 있어 어휘 기반 보조 신호로 보완했습니다.

**Q. 캐싱 최적화는 구체적으로 어떤 식인가요?**
A. Worker 컨테이너별 LRU 인메모리 캐시 3종 — NLI 추론(premise+hypothesis 해시 키), 감성 분석(본문 리드 해시 키), 출처 분류(도메인 키)입니다. 같은 도메인의 반복 분석 시 캐시 적중률이 50% 이상으로 올라가며, 캐시 적중 시 처리 시간이 1.5초에서 0.22초로 약 7배 단축됩니다.
