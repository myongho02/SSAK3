# K3 — 발표 슬라이드용 비교 사례 5건

> 학회 발표에서 "SSAK3가 실제로 어떻게 작동하는가"를 한눈에 보여주는 5건.
> 슬라이드 1장에 표/그래프로 구성하거나, 2~3장에 걸쳐 상세 비교.

                        정상 기사 (N5)           자극적 기사 (S2)

                       환승 할인 확대          역대급 폭로...
                       내달 1일부터 시행       충격적 진실 드러나
─────────────────────────────────────────────────────────────────
본문 일치도 (45%)       82.5점                  80.5점
자극성 분석 (35%)       97.5점 ████████████    15.1점 ██
출처 신뢰도 (20%)       85.0점 (주요 언론사)   35.0점 (출처 불명)
─────────────────────────────────────────────────────────────────

**멘트**: *"두 기사 모두 본문 일치도는 80점대로 비슷하지만, 자극성과 출처에서 67점 차이가 나면서 종합 등급이 명확히 분리됩니다."*

### 2장 — NLI 핵심 가치: 제목-본문 불일치 검출

```
┌──────────────────────────────────────────────────────────────┐
│ 제목: "이재명 대통령, 4월 경제정책 전면 폐기 선언"             │
│                                                                │
│ 본문: "기상청이 다음 주부터 본격적인 장마가 시작될 것으로       │
│       예보했다. 전국적으로 100mm 이상의 많은 비가 예상되며..." │
└──────────────────────────────────────────────────────────────┘

분석 결과:
  • NLI entailment(함의): 0.8%   ← 본문이 제목을 거의 함의하지 않음
  • NLI contradiction(모순): ~  ← (실제 측정값)
  • 본문 일치도: 1.3점 (0~100 중)
  • 종합 점수: 41.7점 → 🟠 의심 기사

⭐ 어휘 기반(코사인 유사도)만으로는 60~70점이 나올 수 있는 케이스를
    NLI 모델이 "의미적 모순"으로 정확히 1.3점으로 분리.
```

**멘트**: *"기존 가짜뉴스 탐지의 가장 큰 한계는 클릭베이트성 제목과 무관한 본문을 못 잡는다는 점입니다. NLI 모델 도입으로 이런 케이스의 본문 일치도가 1.3~20점 사이로 명확히 떨어집니다."*

## 비교 사례 5건 — 상세 데이터

### 사례 1. 정상 기사 (최고 점수)
- **N5**: "서울시, 대중교통 환승 할인 확대… 내달 1일부터 시행"
- 출처: MBC (주요 언론사 85점)
- 종합 **88.2점** → 신뢰 가능 🟢
- 본문일치 82.5 / 자극성 97.5 / 출처 85.0
- **의미**: 정상 기사가 학술 근거(80점) 기준을 명확히 통과

### 사례 2. 자극적 기사 (의심 분류)
- **S2**: "경악!! 정치인 B, 역대급 폭로… 충격적 진실 드러나"
- 출처: 출처 불명 (35점)
- 종합 **48.5점** → 의심 기사 🔴
- 본문일치 80.5 / **자극성 15.1** / 출처 35.0
- **의미**: 자극적 표현 사전 + KR-FinBERT 결합으로 자극성 점수 15.1로 강하게 페널티

### 사례 3. 제목-본문 불일치 (NLI 결정적 효과)
- **M1**: 제목 "이재명 대통령, 4월 경제정책 전면 폐기 선언" vs 본문 (장마 예보)
- 종합 **41.7점** → 의심 기사 🟠
- **본문일치 1.3** / 자극성 97.5 / 출처 35.0
- **의미**: NLI 모델이 의미적 모순을 본문일치도 1.3점으로 거의 0에 가깝게 측정

### 사례 4. 제목-본문 불일치 (다른 도메인)
- **M2**: 제목 "삼성전자 신형 갤럭시 출시" vs 본문 (한전 전력 정비)
- 종합 **46.7점** → 의심 기사 🟠
- 본문일치 19.8 / 자극성 88.0 / 출처 35.0
- **의미**: 일부 어휘는 비슷하지만(`삼성/한전`, `출시/정비` 등) NLI가 의미 모순 감지

### 사례 5. 경계선 케이스 (시스템 한계 노출)
- **N4**: "삼성전자, 3분기 매출 76조원… 전년比 5% 증가"
- 출처: 한국경제 (등록 매체 65점, 한경은 사전 등록되어 있음)
- 종합 **77.9점** → 주의 필요 ⚠️ (신뢰 가능 80점 임계에 2.1점 부족)
- 본문일치 80.0 / 자극성 82.5 / 출처 65.0
- **의미**: 정상 보도이지만 출처 등급이 "등록 매체(65)"라 종합이 80점에 약간 부족.
- **개선 방향**: 한경 같은 경제 전문지를 "주요 언론사" 등급(85점)으로 격상 시 신뢰 가능 분류 가능. 실제 한경은 경제지 1위 매체로 등급 재조정 검토 가치.
