### 슬라이드 5 — 제안 시스템 PRISM 개요 (3가지 해결 방안)

**제목**: PRISM의 핵심 해결 방안 3가지

**가로 3분할 카드**:

| 1️⃣ 메시지 지향 미들웨어 | 2️⃣ Docker 수평 확장 | 3️⃣ 다각적 신뢰도 평가 (XAI) |
|---|---|---|
| RabbitMQ 큐로 요청과 처리 분리 | Worker를 컨테이너로 규격화 | 본문 일치도 + 자극성 + 출처 |
| 트래픽 폭주 시 서버 다운 방지 | 부하 급증 시 수평 확장 | 3가지 정량 지표로 점수화 |
| 비동기 분산 처리 안정성 확보 | 시스템 재구성 없이 확장 | 분석 근거 시각화 제공 |

**시각 요소**: 3개 박스 + 각 박스마다 아이콘 (큐 / 컨테이너 / 차트)

**발표 멘트** (45초):
> "기존 시스템의 단일 서버 병목 문제를 해결하기 위해 세 가지 방법을 고안했습니다. 첫째, RabbitMQ 메시지 큐로 사용자 요청과 실제 처리를 분리하여 트래픽 급증 시에도 서버가 다운되지 않게 했습니다. 둘째, Worker를 Docker 컨테이너로 규격화해 분석 수요 증가 시 컨테이너 수만 늘려 즉시 확장 가능한 구조를 만들었습니다. 셋째, 이진 분류가 아닌 본문 일치도·자극성·출처 신뢰도 3가지 정량 지표로 점수화하고 그 근거를 시각화하는 XAI 접근을 도입했습니다."

### 슬라이드 6 — 전체 시스템 구조

**제목**: 전체 시스템 구조 (Overall Functional Architecture)

**중앙 다이어그램** (논문 그림 1을 활용):
```
사용자 (Web UI)
    ↓ URL 입력
┌─────────────────────────┐
│  Flask API 서버         │ — 요청 형식 검증 + JSON 변환
└─────────┬───────────────┘
          ↓
┌─────────────────────────┐
│  RabbitMQ 메시지 큐      │ — 비동기 작업 분배
└─────────┬───────────────┘
          ↓ 병렬 분배
┌────────┬────────┬────────┐
│Worker-1│Worker-2│Worker-3│ — Docker 컨테이너 (수평 확장)
└────┬───┴────┬───┴────┬───┘
     ▼        ▼        ▼
   ① 크롤링 (newspaper3k + BeautifulSoup)
   ② 3대 지표 분석 (NLI + KR-FinBERT-SC + 출처 매핑)
   ③ DB 저장
          ↓
┌─────────────────────────┐
│  SQLite (WAL 모드)       │ — 분석 결과 + 사용자 격리
└─────────┬───────────────┘
          ↑
┌─────────────────────────┐
│  Streamlit XAI 대시보드   │ — 분석 근거 시각화
└─────────────────────────┘
```

**발표 멘트** (1분 30초):
> "전체 시스템 구조입니다. 사용자가 웹 화면에서 뉴스 URL을 입력하면 Flask API 서버가 요청을 검증해 JSON으로 변환한 후 RabbitMQ 큐에 등록합니다. 큐를 중간에 두는 이 구조 덕분에 트래픽이 갑자기 몰려도 서버가 다운되지 않습니다. 대기열에 들어간 작업은 Docker 환경에서 병렬로 동작하는 여러 Worker가 비동기로 가져가 처리합니다. 각 Worker는 두 단계로 동작하는데, 먼저 newspaper3k 등을 사용해 기사 본문을 크롤링하고, 그 다음 세 가지 지표로 AI 점수를 산출합니다. 결과는 SQLite에 적재되고, Streamlit 기반 XAI 대시보드에서 사용자가 분석 근거를 확인할 수 있습니다."

### 슬라이드 7 — 신뢰도 분석 알고리즘 (3대 지표)

**제목**: 신뢰도 분석 알고리즘 — 다중 지표 앙상블 (Weighted Sum)

**공식 (상단 강조)**:
```
종합 점수 = 본문 일치도 × 0.45 + 자극성 × 0.35 + 출처 신뢰도 × 0.20
```

**3분할 카드**:

| 본문 일치도 (45%) | 자극성 (35%) | 출처 신뢰도 (20%) |
|---|---|---|
| **NLI 모델** (자연어 추론) | **KR-FinBERT-SC** (한국어 감성 모델) | 도메인 → 매체 매핑 |
| 제목이 본문 핵심을 논리적으로 포함하는지 판정 | 텍스트 편향성·감성 강도 측정 | 사전 구축한 신뢰도 DB와 대조 |
| 어긋남·무관 시 점수 큰 폭 감점 | 중립↑ = 가점, 극단·혐오 표현 = 감점 | 검증 언론사 = 높은 점수 |
| [Bowman 2015] | [Alonso 2021] | 메타데이터 기반 |

**시각 요소**: 막대 그래프 형태로 가중치 비율 시각화 (45/35/20).

**발표 멘트** (1분 30초):
> "신뢰도 분석 알고리즘은 다중 지표 앙상블 기법으로 설계했습니다. 최종 점수는 본문 일치도 45%, 자극성 35%, 출처 신뢰도 20%의 가중합으로 계산됩니다. 가장 비중이 큰 본문 일치도는 자연어 추론 NLI 모델로 제목이 본문 핵심을 논리적으로 포함하는지 판정합니다. 어긋나거나 무관하면 점수를 크게 깎아 낚시성 기사를 잡아냅니다. 자극성은 한국어 금융·경제 도메인에 특화된 KR-FinBERT-SC 모델로 텍스트의 편향성과 감성 강도를 측정합니다. 중립에 가까울수록 높은 점수를 부여하고, 극단적이거나 혐오 표현이 끼면 감점합니다. 출처 신뢰도는 발행 도메인의 공신력을 사전 구축한 신뢰도 DB와 대조해 점수화합니다."

### 슬라이드 10 — 개발 현황

**제목**: 개발 현황 — 완료된 기능 + 배포

### 슬라이드 11 — 실험 결과

**제목**: 실험 결과 — Worker 스케일링 + 분류 정확도

**상단 (Worker 스케일링 — 20건 처리 시간)**:
| Worker 수 | 총 처리 시간 | 효과 |
|---|---|---|
| 1개 | 12.2초 | (기준) |
| 2개 | 10.2초 | **17% 단축** |
| 3개 | 10.1초 | 캐시 효과 누적 |

→ Worker 1→2 전환 시 17% 단축. 분산 효과 확인.

**하단 (분류 정확도 — K1 평가 12케이스)**:
| 지표 | 결과 |
|---|---|
| Strict Accuracy | **66.7%** (8/12) |
| Loose Accuracy (±1 등급 허용) | **100%** (12/12) |
| Macro F1 | 0.652 |
| Weighted F1 | 0.693 |

**Confusion Matrix (작은 행렬)**:
```
Expected\Actual  신뢰가능  주의  의심  낮음
신뢰 가능           *4      1     0     0
주의 필요            0     *1     2     0
의심 기사            0      0    *3     1
```
* = 정답 대각선

**시각 요소**: 상단 막대그래프 (Worker 1/2/3 시간), 하단 4x4 매트릭스.

**발표 멘트** (1분 30초):
> "실험 결과입니다. 먼저 분산 처리 성능 검증을 위해 20건의 뉴스 기사를 Worker 1개, 2개, 3개 환경에서 각각 처리한 결과, 1개에서 12.2초, 2개에서 10.2초로 약 17%의 처리 시간 단축이 확인되었습니다. Worker 2개와 3개 차이가 작은 이유는 캐시 효과가 누적되면서 처리 시간이 수렴하기 때문입니다. 분류 정확도 측면에서는 자체 구축한 12케이스 평가 데이터셋에서 엄격 일치 정확도 66.7%, 인접 등급까지 허용한 Loose Accuracy는 100%를 기록했습니다. Macro F1 0.652, Weighted F1 0.693으로, 특히 '신뢰 가능' 등급에서 Precision 1.0의 높은 정확도를 보였습니다. Confusion Matrix를 통해 등급별 분포도 확인할 수 있습니다."
