### 구간 3 — 정상 기사 분석 (45초)

**화면**: Dashboard → 단일 URL 분석
- **입력**: `https://www.yna.co.kr/view/AKR20260515145500063` (연합뉴스 정치)
- **결과**: 종합 **86.8점 / 신뢰 가능 🟢**

**시각 강조 포인트**:
- 본문 일치도 79.2점 (NLI 함의 막대 녹색 강조)
- 자극성 97.5점 (자극 단어 검출 0건)
- 출처 85.0점 (yna.co.kr → 주요 언론사)

**멘트** (45초):
> "주요 통신사 연합뉴스의 정상 정치 기사를 입력하면, NLI 모델이 제목과 본문의 함의 관계를 분석합니다. 본문 일치도 79.2점, 자극성 97.5점, 출처 85.0점이 가중합되어 종합 86.8점 신뢰 가능 등급입니다. **결과 카드 우측에는 각 지표별 분석 근거가 함께 표시**되어, AI가 왜 이 판정을 내렸는지 사용자가 직접 확인할 수 있습니다. 분석 시간은 약 0.76초입니다."

### 구간 4 — 자극성 기사 분석 (45초)

**화면**: Dashboard → 단일 URL 분석
- **입력**: `https://www.mk.co.kr/news/society/12046305` (매경 사회)
- **결과**: 종합 **42.0점 / 의심 기사 🔴**

**시각 강조 포인트**:
- 본문 일치도 19.9점 (NLI 함의 낮음, 모순 막대 적색)
- 자극성 57.2점 (검출 단어: "거짓말", "속여", "챙긴" 등 하이라이트)
- 출처 65.0점 (등록 매체, 주요 통신사보다 낮음)

**멘트** (45초):
> "다음은 자극적 표현이 많은 사회 기사입니다. 제목 '임신했다 알고보니 거짓말, 남친 속여 1천만원 챙긴'에서 **자극 단어 사전이 거짓말·속여·챙긴을 검출**해 자극성 점수가 57.2로 떨어지고, NLI 모델이 제목-본문 의미적 함의가 낮다고 판정해 본문 일치도가 19.9점으로 급락합니다. 종합 42점, 의심 기사 등급입니다. 정상 86.8점과 의심 42점 — **약 44점의 명확한 분리**가 시각적으로 드러납니다."

---

### 구간 5 — 🌟 사용자화 라이브 변경 (45초, 학교 발표 핵심)

**화면**: 동일한 자극성 기사(`12046305`) 결과 화면 유지 + 사이드바 조작

**액션**:
1. 좌측 사이드바 → **분야 프리셋** 셀렉트박스 클릭
2. `[일반 (기본값)]` → `[연예 — 자극성 비중↑]` 변경
3. 슬라이더가 자동으로 45/35/20 → 35/45/20으로 이동
4. 임계치도 80/60/40 → 75/55/35으로 변경
5. 결과 카드 점수가 즉시 재계산되어 표시

**기대 변화**:
- 가중치 변경: 자극성 비중 ↑ → 자극 점수 57.2가 더 큰 영향
- 임계치 완화: 의심 기준 35점 → 같은 raw 점수가 다른 등급으로 표시될 수 있음

**멘트** (45초):
> "PRISM의 가장 큰 차별점이자 **이 발표에서 보여드리고 싶은 핵심 기능**입니다. 학계 기본 가중치 45/35/20은 모든 분야에 일률적으로 적용되지만, 분야 특성이 다릅니다. 연예 기사는 자극적 표현이 흔하기 때문에 임계치를 완화해야 하고, 정치는 출처 비중을 높여야 합니다. **사이드바에서 분야 프리셋을 [연예]로 바꿔보겠습니다.** 같은 raw 점수에 대해 가중치와 임계치가 즉시 재계산되어 새 등급이 표시됩니다. **AI 판정을 사용자가 이해하고 통제할 수 있다는 XAI 철학의 구현**입니다."

### 구간 6 — 대량 분산 분석 (45초)

**화면**: Dashboard → **대량 분석** 탭 → 7개 시연 URL 일괄 입력

**준비**: 메모장에 7개 URL 미리 복사해두기 (시드된 것 그대로)

**액션**:
1. 7개 URL 텍스트박스에 일괄 붙여넣기
2. **분석 시작** 버튼
3. 사이드바 **Worker별 처리 현황** 막대그래프 차오르는 모습
4. 처리 완료 후 등급별 분포 확인

**기대 화면**:
- Worker-1/2/3에 각 2~3건씩 거의 균등 분배
- 결과: 신뢰가능 2 / 의심 5 / 분석불가 0
- 캐시 적중률: NLI/Sentiment는 본문이 다 다르므로 0~10%, **Source 캐시는 90%+ 적중** (같은 도메인 반복)

**멘트** (45초):
> "마지막으로 7건 일괄 분석으로 분산 처리를 보여드립니다. RabbitMQ 큐가 작업을 3개 Worker에 라운드로빈 분배하고, 사이드바 막대그래프에서 균등 분배가 가시화됩니다. 캐시는 **출처 캐시 97% 적중**으로 같은 도메인 반복 처리 시 매우 빠릅니다. 실험 측정에서는 1,000건 처리 시 3-Worker 구성으로 시간당 1만 3천 6백 건의 처리량을 검증했습니다."

---

### 구간 7 — 분석 근거 깊이 (30초, 시간 여유 시)

**화면**: 결과 카드 중 하나 클릭 → 세부 근거 expander 펼치기

**보여줄 것**:
- 자극 단어 카테고리별 분포 (과장/혐오/선정/공포)
- 검출된 키워드 하이라이트 + 면제 처리 단어
- NLI 함의/중립/모순 확률 막대
- 출처 매체 분류 표시

**멘트** (30초):
> "AI 결정의 모든 근거가 표시됩니다. 자극 단어는 4개 카테고리로 분류되고, NLI 함의 확률이 함의·중립·모순 막대로 표시되며, 출처 매체는 주요 언론사·등록 매체·출처 불명으로 분류됩니다. **단순 가짜/진짜 이진 판정이 아닌, 설명 가능한 점수+근거 시스템**입니다."

## 시연 트러블슈팅

| 문제 | 즉시 조치 |
|---|---|
| Worker 컨테이너 떠있지 않음 | `docker compose up -d worker-1 worker-2 worker-3` |
| URL 404 (만료) | demo_seed_urls.json에서 다음 후보로 교체 |
| 큐 막힘 | `docker compose exec rabbitmq rabbitmqctl purge_queue news_queue` |
| 대시보드 새로고침 실패 | Streamlit 우상단 `Rerun` 버튼 클릭 |
| 분석 매우 느림 | 캐시 휘발됨 → `python3 demo_seed.py` 다시 실행 |
| 사이드바 슬라이더가 안 움직임 | 분야 프리셋 먼저 [일반]으로 초기화 후 다시 변경 |
