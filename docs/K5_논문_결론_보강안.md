## Ⅲ. 결론 — v2 (기존)

> 본 연구는 RabbitMQ와 Docker를 결합한 메시지 큐 기반 비동기 분산 처리 시스템을 설계해 대규모 뉴스 데이터 분석에서 확장성과 실시간 처리 성능을 함께 끌어올렸다. 객관적인 판별을 위해서는 제목-본문 일치도(45%), KR-FinBERT-SC 기반 감성·자극성 분석(35%), 출처 신뢰도(20%)를 묶은 다중 지표 AI 알고리즘을 적용했다. 단순히 결과 수치만 알려주는 방식에서 한걸음 나아가, 설명 가능한 AI(XAI) 대시보드로 분석 근거를 시각적으로 함께 보여주도록 한점도 본 연구의 특징이다.
>
> Flask API 서버부터 Streamlit 대시보드 까지의 전체 마이크로 서비스는 Docker Compose로 묶어 통합 실행이 가능하며, 이를 통해 배포 안정성과 일관된 동작 환경을 확보했다.
>
> 다만 본 시스템에는 보완할 부분도 남아 있다. 현재는 세가지 지표만으로 신뢰도를 평가하기 때문에, 다양하게 변형되는가짜뉴스 패턴을 모두 잡아 내기에는 한계가 있다. 또 각 항목의 가중치는 선행연구를 참고해 정한 초기값일 뿐 데이터 기반 최적화를 거친 값은 아니어서, 특정 상황에서는 결과가 한쪽으로 치우칠 가능성도 있다.
>
> 향후 연구에서는 새로운 기능(Feature)을 추가해 분석 모델의 정확도를 높이고, 실제 데이터를 활용한 가중치 최적화와 외부 지식기반 검증 시스템 연동을 통해 더 정밀한 가짜뉴스 탐지 체계를 만들고자 한다.

## Ⅲ. 결론 — v3 (수정안)

> 본 연구는 RabbitMQ와 Docker를 결합한 메시지 큐 기반 비동기 분산 처리 시스템을 설계해 대규모 뉴스 데이터 분석에서 확장성과 실시간 처리 성능을 함께 끌어올렸다. 객관적인 판별을 위해서는 **자연어 추론(NLI) 모델 기반의 제목-본문 일치도(45%)**, KR-FinBERT-SC 기반 감성·자극성 분석(35%), 출처 신뢰도(20%)를 묶은 **다중 지표 앙상블 AI 알고리즘**을 적용하였다. 각 지표 내부에서도 모델 신호와 규칙 기반 신호를 결합하여 단일 모델 의존도를 낮추었으며, **본문 리드와 출처 도메인에 대한 LRU 캐시 계층을 통해 반복 추론 비용을 절감**했다. 단순히 결과 수치만 알려주는 방식에서 한걸음 나아가, 설명 가능한 AI(XAI) 대시보드로 분석 근거를 시각적으로 함께 보여주도록 한 점도 본 연구의 특징이다.
>
> 시스템 검증 단계에서는 정상 보도·자극적 보도·제목-본문 불일치·출처 불명 등 **네 가지 카테고리의 평가 데이터셋(12건)**을 구성해 분류 정확도를 측정하였다. 결과 본 시스템은 **Strict Accuracy 66.7%(예상 등급 정확 일치)와 Loose Accuracy 100%(인접 등급 1단계 이내 분류)**를 달성하였다. 특히 제목과 본문이 의미적으로 어긋나는 낚시성 기사에서 본문 일치도 점수가 1.3∼19.8점 사이로 강하게 분리되어, NLI 모델 도입의 유효성이 검증되었다. 또한 정상 기사의 평균 종합 점수(84.7점)와 자극적 기사의 평균 종합 점수(51.9점) 사이에 약 33점의 분리도가 확보되어 등급 변별력이 입증되었다.
>
> Flask API 서버부터 Streamlit 대시보드까지의 전체 마이크로 서비스는 Docker Compose로 묶어 통합 실행이 가능하며, **GitHub Actions 기반 CI/CD 파이프라인과 GHCR(GitHub Container Registry)을 활용한 자동 이미지 배포 체계**를 함께 구축하여 배포 안정성과 일관된 동작 환경을 확보했다.
>
> 다만 본 시스템에는 보완할 부분도 남아 있다. 현재는 세 가지 지표만으로 신뢰도를 평가하기 때문에, 다양하게 변형되는 가짜뉴스 패턴을 모두 잡아내기에는 한계가 있다. 또 각 항목의 가중치는 선행 연구를 참고해 정한 초기값일 뿐 데이터 기반 최적화를 거친 값은 아니어서, 특정 상황에서는 결과가 한쪽으로 치우칠 가능성도 있다. 평가 데이터셋 역시 12건의 합성·실제 사례를 혼합한 소규모 표본이라, **공개 가짜뉴스 데이터셋과의 대규모 비교 평가가 추가로 필요하다.**
>
> 향후 연구에서는 새로운 기능(Feature)을 추가해 분석 모델의 정확도를 높이고, 실제 데이터를 활용한 가중치 최적화와 외부 지식 기반 검증 시스템 연동을 통해 더 정밀한 가짜뉴스 탐지 체계를 향상시키고자 한다. **또한 사용자별 분석 이력 격리와 분야별 사용자화 기능을 강화하여, 단순한 분석 도구에서 개인 맞춤형 신뢰도 어시스턴트로 확장할 계획이다.**
