## 1. 평가 데이터셋 구성

| 카테고리 | 건수 | 설명 | 예상 등급 |
|---|---|---|---|
| **normal** (정상 기사) | 5건 | 주요 언론사 일반 보도 | 신뢰 가능 |
| **sensational** (자극적) | 3건 | "충격/경악/폭로" 등 자극어 다수 | 주의/의심 |
| **mismatch** (제목-본문 불일치) | 3건 | 제목과 본문이 의미적으로 어긋남 | 의심 |
| **unknown_source** (출처 불명) | 1건 | 등록되지 않은 매체 | 주의 |

**합성 케이스**: 제목/본문/출처를 직접 작성. 크롤링 변수 제거하고 알고리즘 자체의 분류력 측정.

## 2. 종합 결과

| 지표 | 값 | 의미 |
|---|---|---|
| **Strict Accuracy** | **66.7%** (8/12) | 예상 등급과 정확히 일치 |
| **Loose Accuracy** | **100%** (12/12) | 인접 등급 1칸 이내 (실용적 정확도) |

> Loose Accuracy 100%는 **모든 케이스가 예상 등급의 인접 범위 안에 분류**되었음을 의미. 즉 시스템이 "정상↔의심"을 뒤바꾸는 결정적 오류는 0건.

### 카테고리별 Strict Accuracy
| 카테고리 | 정확도 | 비고 |
|---|---|---|
| Normal | 4/5 = 80% | 1건만 신뢰 가능→주의 필요로 인접 분류 (점수 77.9, 임계 80에 2.1점 부족) |
| Sensational | 2/3 = 66.7% | 1건만 주의 필요→의심 기사로 인접 분류 |
| Mismatch | 2/3 = 66.7% | 1건만 의심 기사→신뢰 낮음으로 인접 분류 (37.2점, 40 임계에 2.8점 부족) |
| Unknown source | 0/1 | sample 1건이라 통계적 의미 약함 |

## 4. 발표용 핵심 인사이트

### 🎯 인사이트 1 — NLI가 제목-본문 불일치를 결정적으로 검출
3건의 mismatch 케이스에서 본문일치도가 **1.3 / 19.8 / 6.1점**으로 매우 낮게 산출.
- 어휘 기반 코사인 유사도만으로는 0~50점 사이 모호한 점수가 나옴
- NLI 모델 도입(가중치 60%) 효과로 의미적 모순을 강하게 페널티

**발표 멘트**: *"제목과 본문이 의미적으로 어긋나는 낚시성 기사 3건에서 본문일치도가 1~20점으로 매우 낮게 측정됐습니다. 어휘만 보는 기존 방식으로는 잡기 어려운 유형을 NLI 모델이 명확히 분리해냅니다."*

### 🎯 인사이트 2 — 정상 vs 자극적 기사 명확한 분리
- 정상 기사 평균 종합 점수: **84.7점**
- 자극적 기사 평균 종합 점수: **51.9점**
- 분리 폭: **약 33점** (등급 2단계 차이)

### 🎯 인사이트 3 — 인접 등급 분류 100% (실용성 검증)
모든 12건이 예상 등급의 ±1단계 이내에 정확히 분류됨. 즉 **"정상 기사를 신뢰 낮음으로 잘못 분류"** 같은 결정적 오류는 0건. 사용자 입장에서 시스템 판단을 신뢰하고 참고 가능.

## 5. 향후 정확도 향상 방향 (논문 결론 보강용)

1. **등급 임계치 데이터 기반 최적화**
   - 현재 80/60/40는 학술 근거 기반 초기값
   - 위 N4 (77.9점)나 M3 (37.2점)처럼 경계선 케이스가 인접 등급으로 떨어지는 패턴 확인
   - 실제 대규모 라벨링 데이터로 임계치를 5~10점 조정 시 Strict Accuracy 80%+ 도달 가능

2. **출처 사전 확장**
   - 현재 주요/등록 매체 ~100개. 한국 등록 인터넷 매체 약 600~700개로 확장 시 unknown_source 분류 정확도 향상

3. **합성 데이터 한계**
   - 본 평가는 합성 데이터 위주라 학술적 무게 제한
   - SNU 팩트체크 데이터셋 또는 KFND 등 공개 가짜뉴스 데이터셋과 연동 시 더 객관적 검증 가능
