# SSAK3 팀원 초심자 설치 가이드

> 처음 해보는 사람도 따라할 수 있게 단계별로 정리했어요.
> **macOS / Windows 모두 지원**합니다.
> 막히면 명호에게 어느 단계에서 막혔는지 + 화면 캡쳐 보내주세요.

---

## 📋 전체 흐름 (총 5~10분)

```
1. Docker Desktop 설치        ← 운영체제별 1회 (5분)
2. VS Code 설치               ← 1회 (3분)
3. GitHub에서 코드 받기        ← 1회 (2분)
4. VS Code로 폴더 열고 명령어 실행 ← 매번 (1분)
5. 브라우저로 접속             ← http://localhost:8501
```

---

## STEP 1. Docker Desktop 설치

### macOS

1. https://www.docker.com/products/docker-desktop/ 접속
2. **"Download for Mac"** 옆 화살표 클릭
   - Apple 실리콘 (M1/M2/M3/M4): **"Mac with Apple chip"** 선택
   - Intel Mac: **"Mac with Intel chip"** 선택
   - 본인 Mac이 어느 쪽인지 모르면: 좌측 상단 🍎 → "이 Mac에 관하여" → "칩"이 "Apple M..."이면 Apple chip
3. 다운로드된 `.dmg` 파일 더블클릭 → Docker 아이콘을 Applications 폴더로 드래그
4. Applications에서 **Docker** 실행 → "Open" 클릭 → 비밀번호 입력
5. **상단 메뉴 바에 고래 🐳 아이콘**이 생겨야 정상

### Windows

1. https://www.docker.com/products/docker-desktop/ 접속
2. **"Download for Windows"** 클릭
3. `Docker Desktop Installer.exe` 실행 → 모든 옵션 기본값 → 설치
4. 재부팅 → Docker Desktop 실행 → 약관 동의

### 설치 확인 (둘 다 공통)

VS Code 또는 터미널에서:
```bash
docker --version
```
**`Docker version 24.x.x` 같은 결과가 나오면 OK**.

## STEP 2. VS Code 설치

1. https://code.visualstudio.com/download
2. 본인 운영체제 클릭 → 다운로드 → 설치
3. 첫 실행 시 한국어 확장 설치 권장 (Cmd/Ctrl+Shift+X → "Korean Language Pack")

---

## STEP 3. GitHub에서 코드 받기

### 방법 A — VS Code에서 직접 clone (권장, 가장 쉬움)

1. VS Code 실행
2. 좌측 사이드바 **Source Control** 아이콘 (가지처럼 생긴 모양) 클릭
3. **"Clone Repository"** 버튼
4. 상단 입력창에 다음 붙여넣기:
   ```
   https://github.com/myongho02/SSAK3.git
   ```
5. Enter → "어디에 저장할지" 묻는 창 → 데스크톱 또는 원하는 폴더 선택
6. 잠시 후 "Open?" 묻는 알림 → **"Open"** 클릭
7. "Do you trust the authors of the files in this folder?" → **"Yes, I trust the authors"**

### 방법 B — ZIP 다운로드 (Git 설치 안 하고 싶을 때)

1. https://github.com/myongho02/SSAK3 접속
2. 초록색 **"Code"** 버튼 클릭
3. **"Download ZIP"** 클릭
4. ZIP 압축 풀기 (보통 다운로드 폴더에 `SSAK3-main` 폴더 생김)
5. VS Code 실행 → File → Open Folder → 압축 푼 폴더 선택

---

## STEP 4. VS Code에서 명령어 실행

### 4-1. 터미널 열기

VS Code 상단 메뉴: **Terminal → New Terminal**
- 단축키: macOS `Ctrl+\``  /  Windows `Ctrl+\``
- 화면 아래쪽에 검은 창(터미널)이 생기면 OK

### 4-2. 환경변수 파일 만들기 (1회만)

터미널에 다음 한 줄 붙여넣고 Enter:

```bash
echo "GHCR_OWNER=myongho02" > .env
```

좌측 파일 트리에 **`.env`** 파일이 생겨야 정상 (점으로 시작해서 안 보이면 화면 새로고침: 파일 트리 우클릭 → Refresh).

### 4-3. 이미지 받기 (1~2분 — 첫 1회만)

```bash
docker compose -f docker-compose.prod.yml pull
```

다음과 같이 진행 표시줄이 보이면 OK:
```
[+] Pulling 9/9
 ✔ rabbitmq Pulled
 ✔ api Pulled
 ✔ worker-1 Pulled
 ...
```

> **에러가 난다면**: `denied: ... unauthorized` → 명호에게 "GHCR Public 전환 했는지" 물어보세요.

### 4-4. 가동

```bash
docker compose -f docker-compose.prod.yml up -d
```

5~10초 후 다음과 같이:
```
✔ Container ssak3-rabbitmq-1   Started
✔ Container ssak3-api-1        Started
✔ Container ssak3-worker-1-1   Started
✔ Container ssak3-worker-2-1   Started
✔ Container ssak3-worker-3-1   Started
✔ Container ssak3-dashboard-1  Started
```

### 4-5. 상태 확인

```bash
docker compose -f docker-compose.prod.yml ps
```

**6개 컨테이너가 모두 `Up`이면 정상**. `(healthy)`까지 뜨려면 30초~1분 더 걸릴 수 있어요 (모델 첫 로딩).

---

## STEP 5. 브라우저로 접속

1. 브라우저 (Chrome / Safari / Edge) 열기
2. 주소창에 입력: **http://localhost:8501**
3. SSAK3 게이트 페이지가 보이면 ✅ 성공!

### 첫 사용

1. **"📝 회원가입"** 탭 → 아이디 (3~30자) + 비밀번호 (영문+숫자 8자 이상)
2. 가입 후 자동 로그인됨
3. URL 입력창에 네이버 뉴스 URL 붙여넣기 (예: `https://n.news.naver.com/mnews/article/...`)
4. **"분석 요청"** 클릭
5. 5~10초 후 결과 카드가 화면에 나타남 (자동 갱신 안 되면 새로고침)

### 모바일에서도 사용 가능

같은 와이파이의 모바일에서:
1. 노트북 IP 확인 (macOS: 시스템 설정 → 네트워크 → Wi-Fi → 세부정보)
2. 모바일 브라우저에서 `http://<노트북_IP>:8501` (예: `http://192.168.0.10:8501`)

## 📌 일상 명령어 (자주 쓰는 것만)

VS Code 터미널에서:

```bash
# 종료 (작업 끝나면)
docker compose -f docker-compose.prod.yml down

# 다시 가동 (컴퓨터 재부팅 후 등)
docker compose -f docker-compose.prod.yml up -d

# 새 버전이 올라왔을 때 (명호가 알려주면)
docker compose -f docker-compose.prod.yml pull
docker compose -f docker-compose.prod.yml up -d

# 로그 보기 (분석 진행 상황)
docker compose -f docker-compose.prod.yml logs -f worker-1

# 상태 확인
docker compose -f docker-compose.prod.yml ps
```

## 🛠 자주 발생하는 문제

### "Cannot connect to the Docker daemon"
→ Docker Desktop이 안 켜진 거예요. 메뉴 바 🐳 아이콘 확인.

### `denied: ... unauthorized`
→ GHCR 이미지가 비공개 상태. 명호에게 알려주세요.

### "port is already allocated"
→ 8501 또는 5001 포트가 이미 다른 곳에서 쓰임. 다음으로 확인:
```bash
# macOS
lsof -i :8501
# Windows
netstat -ano | findstr 8501
```
다른 SSAK3가 떠 있다면 종료 후 재시도.

### Apple Silicon Mac에서 분석이 너무 느림
→ Docker Desktop 설정 (⚙️) → General → **"Use Rosetta for x86_64/amd64 emulation on Apple Silicon"** 체크 켜기 → 재시작.

### http://localhost:8501 접속 안 됨
1. 30초 더 기다리기 (Streamlit 첫 시작이 느림)
2. `docker compose -f docker-compose.prod.yml ps`로 dashboard가 `(healthy)`인지 확인
3. `docker compose -f docker-compose.prod.yml logs dashboard`로 에러 확인

### 회원가입 실패 — "비밀번호는 영문과 숫자를 모두 포함"
→ 비밀번호에 영문 글자와 숫자를 모두 포함시키세요. 예: `Test1234`

### 분석 결과가 안 보임
→ 본인이 분석한 결과만 보입니다. 다른 팀원이 분석한 건 격리되어 있음.

## 🎯 회원/사용자별 격리

- **본인 분석은 본인만 봄**: 다른 팀원이 같은 노트북을 써도 본인 계정으로 로그인해야 본인 결과를 봄
- **모든 팀원은 각자 회원가입**: 명호 / 팀원1 / 팀원2 등 각자 아이디 만들어서 사용
- **공유하고 싶을 때**: 본인 분석 결과 → "🔗 공유 링크 발급" → URL을 카톡으로 공유 (받은 사람은 인증 없이 읽기 가능)
