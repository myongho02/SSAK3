# 팀원 배포 가이드 (SSAK3)

> 이 가이드는 팀원이 SSAK3를 본인 노트북에서 1분 안에 띄울 수 있게 하는 절차입니다.
> 명호가 코드를 수정·푸시할 때마다 GitHub Actions가 자동으로 빌드해서 GHCR에 이미지를 올려둡니다.
> 팀원은 빌드 없이 그 이미지를 그대로 받아서 실행하면 됩니다.

---

## 1. 사전 준비 (1회만)

### 1-1. Docker Desktop 설치
- macOS: https://www.docker.com/products/docker-desktop/ → "Mac with Apple chip" 또는 "Mac with Intel chip"
- Windows: 위 같은 페이지 → "Windows"
- 설치 후 Docker Desktop 실행 (메뉴 바에 고래 아이콘이 떠 있어야 함)

### 1-2. Git 설치 확인
```bash
git --version    # 2.x 이상이면 OK
```
없으면 macOS는 `xcode-select --install`, Windows는 https://git-scm.com/

---

## 2. 첫 가동 (5분)

```bash
# 1) 저장소 받기
git clone https://github.com/myongho02/SSAK3.git
cd SSAK3

# 2) 환경변수 설정 (한 줄)
echo "GHCR_OWNER=myongho02" > .env

# 3) GHCR에서 이미지 받기 (~1~2분, 인터넷 속도에 따라)
docker compose -f docker-compose.prod.yml pull

# 4) 가동
docker compose -f docker-compose.prod.yml up -d

# 5) 6개 컨테이너 모두 healthy인지 확인
docker compose -f docker-compose.prod.yml ps
```

**상태 확인 — 다음과 비슷하게 떠야 정상**:
```
NAME              STATUS
ssak3-api-1       Up (healthy)
ssak3-dashboard-1 Up (healthy)
ssak3-rabbitmq-1  Up (healthy)
ssak3-worker-1-1  Up
ssak3-worker-2-1  Up
ssak3-worker-3-1  Up
```

**접속**: 브라우저에서 http://localhost:8501

---

## 3. 사용 흐름

1. http://localhost:8501 접속 → 회원가입 (영문+숫자 8자 이상 비밀번호)
2. URL 입력창에 네이버 뉴스 URL 붙여넣기 → 분석 요청
3. 결과 카드에서 점수/등급/근거 확인
4. 좌측 사이드바 "📈 내 통계" 페이지에서 본인 분석 통계 + CSV 다운로드 + 공유 링크 발급
5. "⚙️ 계정 설정"에서 비밀번호 변경 / 회원 탈퇴

**다른 팀원 결과는 안 보임** — 사용자별로 격리되어 있습니다.

## 4. 일상 명령어

```bash
# 종료
docker compose -f docker-compose.prod.yml down

# 다시 가동 (빌드 X, 1초)
docker compose -f docker-compose.prod.yml up -d

# 새 버전이 GHCR에 올라왔으면 갱신
docker compose -f docker-compose.prod.yml pull
docker compose -f docker-compose.prod.yml up -d

# 로그 확인
docker compose -f docker-compose.prod.yml logs -f api
docker compose -f docker-compose.prod.yml logs -f worker-1

# DB 초기화 (개인 분석 이력 다 지우기)
docker compose -f docker-compose.prod.yml down -v
docker compose -f docker-compose.prod.yml up -d
```

## 5. 자주 발생하는 문제

### "permission denied" / "denied: ... unauthorized"
GHCR 이미지가 비공개라 발생. 명호에게 **이미지 public 전환 요청**.
임시 우회: `docker login ghcr.io` 후 GitHub Personal Access Token으로 인증.

### 컨테이너가 "unhealthy"
- API: 모델 로딩 중일 수 있음. 30초 후 다시 `docker compose ... ps`
- RabbitMQ: 포트 5672/15672 충돌 확인
- Dashboard: 포트 8501이 이미 쓰이는지 확인 (`lsof -i :8501`)

### 분석이 너무 느림
- `docker compose -f docker-compose.prod.yml logs worker-1` 확인
- 첫 분석 1건은 모델 워밍업으로 ~5초 소요. 이후엔 1~2초

### 분석 시 404 에러
- 네이버 뉴스 URL 형식 변경되었거나 만료된 기사
- 다른 URL로 시도

## 6. FAQ

**Q. 팀원끼리 분석 결과 공유하고 싶은데?**
- 본인 결과 카드에서 "🔗 공유 링크 발급" → URL 복사 → 카톡으로 공유
- 받은 사람은 인증 없이 그 URL 열면 결과 보임 (read-only)

**Q. 모바일에서도 쓸 수 있나?**
- 노트북과 같은 와이파이라면: `http://<노트북_IP>:8501` (예: `http://192.168.0.10:8501`)
- 외부에서 접속하려면 명호가 `docker compose --profile tunnel up -d`로 ngrok 가동

**Q. 데이터는 어디 저장되나?**
- Docker 볼륨 `shared-data`. 컨테이너 삭제해도 데이터는 유지됨 (volume 따로 삭제하지 않는 한)
- 본인 데이터는 본인만 접근. 다른 팀원이 같은 노트북에 와도 본인 계정으로 로그인해야 본인 데이터 봄

**Q. 명호가 코드 업데이트했다고 알림 받음. 어떻게 갱신?**
```bash
docker compose -f docker-compose.prod.yml pull       # 새 이미지 받기
docker compose -f docker-compose.prod.yml up -d      # 자동 재시작 (다운타임 ~5초)
```
